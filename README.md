# CookieBot

Run the GUI:

```powershell
python bot_image_match.py
```

Set the template folder and numbered image range, then select **Start** or **Stop**.

The original command-line mode also remains available:

```powershell
python bot_image_match.py --numbered 1 8 --threshold 0.9 --interval 0.6 --cooldown 1.2 --grayscale
```
